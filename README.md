# EventPulse

Multi-venue event check-in and analytics admin — Next.js + Supabase (Auth, Postgres, RLS). Portfolio proof app.

## Local setup

```bash
pnpm install
cp .env.example .env.local   # fill from `supabase status` after `supabase start`
supabase start
pnpm dev
```

See [AGENTS.md](./AGENTS.md) for verify commands and stack facts. Phase order: [docs/roadmap.md](./docs/roadmap.md).
